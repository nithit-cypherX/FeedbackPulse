# FeedbackPulse

A planned backend API that classifies short English feedback as negative,
neutral, or positive for human review.

## Status

Proposal stage. Application development and cloud deployment have not started.
The latency and cost figures are planning targets, not measured results.
Instructor approval is required before building the system.
